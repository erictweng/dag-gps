# Workspace import — Phase 1 inventory and preview

Status: implemented intermediate schemas for M1 tasks 1.3/1.4. This is not a
reviewed architecture, an approved legacy map, a workspace server, or an agent
feature.

## Production API

```python
from app.repositories import acquire_repository
from app.snapshots import build_workspace_snapshot

acquired = acquire_repository(
    "https://github.com/owner/repository", cache_root, full_commit_or_none
)
result = build_workspace_snapshot(
    acquired,
    output_dir,
    limits=None,
    extractor_options=None,
    progress=None,
    cancel=None,
)
```

`acquire_repository` is the accepted Phase 1 acquisition boundary. The snapshot
builder revalidates its bare cache and immutable commit, reads the authoritative
Git tree and blobs, and never checks out source. `progress` receives an
`inventory-ready` event before the shipped static extractor starts. A second
identical repo/commit/manifest/extractor/options build validates and reuses the
published bytes.

`result` contains `snapshot_id`, `cache_hit`, exact output paths, and read-back
SHA-256 values. Outputs are:

- `inventory.json` (`dag-gps-inventory/v1`): every committed regular file,
  exact byte count/SHA-256, UTF-8/binary kind, logical line count when known,
  extraction inclusion/reason, source identity, limits, and manifest digest.
- `preview.json` (`dag-gps-dependency-preview/v1`): supported static file links,
  source-file witnesses with unknown line ranges explicitly null, proposed
  parent-folder grouping, retained file/layer cycles, exact extraction scope,
  and unresolved/unsupported/external/unscanned diagnostics.
- `index.html`: one self-contained offline inspection page. Every inventory
  path is a native keyboard-accessible button. Activation exposes inert path,
  hash, content kind, line count, extraction reason, provisional group and
  incident directed-link/source-witness details even when extraction is partial,
  unsupported, or cyclic. It has no external resources or runtime network
  request. Embedded untrusted data escapes `<` and display writes use
  `textContent`.
- `receipt.json`: source/cache identity, exact complete output membership and
  hashes, plus a generated byte-fingerprint manifest for the adapter,
  acquisition validator, extractor and local preview helpers.

These are explicit Phase 1 intermediate schemas, not a relabeled complete
`dag-gps-workspace/v1` trusted snapshot. They therefore do not invent mandatory
map/scorer metadata or bypass `app/contracts.py`. Grouping is always
`{"status":"proposed","reviewed":false}`. Consent defaults and agent controls
remain unchanged and false.

## Safety and failure behavior

Defaults are 20,000 members, 256 MiB total expanded bytes, 8 MiB per file,
32 MiB tree output, 4 MiB child stdout/stderr, 16 MiB extractor graph
sidecar, and a 60 second operation deadline. The sidecar is monitored while the
trusted child runs and checked with `lstat` and byte length before decoding.
Callers may lower these independent console/graph limits. Unknown limit/option
keys reject. Cancellation is checked between blobs and during trusted child
processes.

Paths are literal normalized UTF-8 POSIX paths. Absolute/traversing/control,
backslash, non-NFC, duplicate, and portable collisions reject. The strict
portable key is component-wise NFC plus case-folding; trailing dots/spaces are
rejected rather than rewritten, as are Windows device components (`CON`, `PRN`,
`AUX`, `NUL`, `COM1`-`COM9`, and `LPT1`-`LPT9`, including extensions).
Source tokens are never normalized into a different path.
Symlinks, submodules, and special Git modes reject; no target is followed.
Executable Git modes are read only as bytes and are never run. `.gitattributes`
`export-ignore`/`export-subst` cannot omit or alter inventory because no archive
is used. Binary and unsupported files stay visible without graph links.

The builder materializes bounded blobs into an owned private staging directory
only for the trusted shipped static parser. It invokes no imported command,
hook, dependency, README instruction, package manager, or source interpreter.
The parser remains the documented lexical JS/TS and AST Python/static SQL scope;
it is not universal semantic or runtime analysis.

Publication stages and validates the whole output directory, then renames it.
Caught promotion/readback failures restore the prior validated directory.
Existing output is replaceable only when it contains exactly the three required
outputs plus `receipt.json`; all four must be standalone, single-link regular
files, the receipt identity/schema/digests/producer set must be bounded and
complete, and every output digest must match. Missing/extra names, unrelated
files, symlinks, hardlink aliases and special files reject before output bytes
are read and preserve the prior directory. `receipt.json` is capped at
`MAX_RECEIPT_BYTES` (64 KiB): an oversized receipt rejects from its `lstat`
size before it is opened, and an in-limit receipt is read once through a
no-follow descriptor whose device/inode must match the checked file. Generated
receipts are checked against the same cap before staging. This is cooperating-writer integrity,
not cryptographic authentication against an arbitrary same-user process that can
forge all files, and it makes no same-user TOCTOU guarantee. It is not a
power-loss/concurrent-reader transaction. Use one writer. Manual overlays belong
in a separate sibling directory such as `manual-overlays/`; the builder never
reads them as review or overwrites them.

## Diagnostics and cache identity

Unresolved imports, unsupported constructs, external packages, non-source
connections, unscanned source paths, file cycles, and layer cycles remain
separate. Any extraction gap or unsupported inventory makes the preview
`partial`. Unresolved/ownership errors or layer cycles set
`publicationBlocked`; the inventory and file evidence remain inspectable.
No edge is deleted to force a DAG.

The stable snapshot/cache ID hashes repository identity, full commit, exact
source-manifest digest, extractor version, canonical options, active safety
limits, and a generated SHA-256 set for `app/snapshots.py`, the accepted
acquisition validator, the trusted extractor and each imported local helper that
determines inventory/preview output. Producer bytes are fingerprinted before
work and again before publication; drift rejects, while a changed producer set
creates a different ID and prevents reuse. Timestamps and moving refs are
excluded. This byte binding does not authenticate arbitrary in-memory
monkeypatches by a same-user process. Changing source, producer, options, or
limits creates a different ID.

## Reproduction

Focused tests:

```sh
python3 -m unittest discover -s tests -p test_workspace_snapshot.py -v
python3 -m unittest discover -s tests -p test_workspace_preview.py -v
python3 -m unittest discover -s tests -p test_repository_import.py -v
```

Pinned public smoke:

```sh
python3 scripts/smoke_workspace_import.py \
  --repo-url https://github.com/pallets/itsdangerous \
  --expected-commit 672971d66a2ef9f85151e53283113f33d642dabd \
  --cache-root artifacts/phase1-inventory-preview/git-cache \
  --output artifacts/phase1-inventory-preview/itsdangerous \
  --receipt artifacts/phase1-inventory-preview/real-smoke.json
```

The smoke runs the production acquisition/build twice, requires inventory to be
the first build event, validates cache reuse and records a Python audit-hook list
of every subprocess. Only the trusted absolute Git and shipped
`scripts/import_graph.py` Python invocation are permitted. This instrumentation
supports the no-source-execution/no-model-process claim within the Python
process boundary; it is not a host-wide syscall trace. Git itself performs the
approved GitHub network transport.

## Preview display of proposed groups

The offline page lists proposed groups and group-to-group links by their folder
label (for example `(root)`, `screener`), sorted by label. Opaque
`folder-<hash>` IDs remain internal lookup keys in `preview.json` and are shown
only if a group has no label. File details report the group label. Grouping
remains proposed and unreviewed.
